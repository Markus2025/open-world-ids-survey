# Primary studies of the survey on closed-loop open-world intrusion detection in IoT

This repository holds the list of primary studies for the manuscript

> T. Zhang, P. Kar, A. Guerra Manzanares, and H. Yu, "A Survey on Closed-Loop Open-World Intrusion Detection in IoT: Unknown Handling, Incremental Adaptation, and Deployment Challenges," manuscript under review.

## Content

| File | What it is |
|---|---|
| `Supplementary_Material.pdf` | Table S1 with all 138 primary studies that the survey compares (11 pages) |

The survey compares 138 primary studies. Its reference list cites 83 of them. Table S1 lists all 138, so that every compared study can be found.

Table S1 has one row for each study. The rows are sorted by the surname of the first author. Each row gives

- the full reference with its DOI or arXiv number,
- the stage labels of the study (recognition, candidate handling, adaptation, retention, evaluation),
- whether the study is a closed-loop study (E: the loop is run in an experiment, M: the loop is described in the method only),
- the codes for the 16 reporting requirements of the survey (R: reported, P: partly reported, --: not reported).

The first page of the PDF explains every column and every code.
